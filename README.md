# hyoyul-homepage

효율경영자문(주) 홈페이지 재구축 저장소.

현행 사이트 `https://www.hyoyul.co.kr` 는 clickn.co.kr 임대형 빌더 기반이며,
사이트맵 등록 15개 페이지 전량이 빌더 템플릿 예시문구 상태다.
이 저장소는 해당 사이트를 Next.js 기반으로 새로 구축하기 위한 작업 공간이다.
