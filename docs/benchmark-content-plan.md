# 카테고리별 콘텐츠 설계안 (벤치마크 분석)

작성일 2026.08.21 / 목적: 카테고리 페이지에 채울 내용의 구조 확정

---

## 1. 벤치마크 조사 결과

4개 유형의 사이트를 조사함. 각 유형이 잘하는 지점이 다름.

### 1-1. 법무법인 율촌 (전문가 조직형)

- 메뉴: 전문분야 / 변호사 검색 / 자료실(뉴스·판례·뉴스레터·영상) / 세미나 / 법인소개(개요·역사·수상) / 공익활동
- 특징: 전문분야를 업무별 × 산업별 이중 분류. 구성원 검색 기능. 자료실이 독립 메뉴로 콘텐츠 자산을 축적함
- 채택할 것: 자료실(인사이트) 축적 구조, 수상·연혁을 법인소개 하위에 체계화

### 1-2. KMAC 한국능률협회컨설팅 (대형 컨설팅형)

- 메뉴: 서비스 5개 대분류(경영혁신 / AX·ESG / 정부행정 / 가치혁신 / HR) × 산업별 서비스 교차 분류 + 뉴스&인사이트
- 특징: 서비스 분류가 깊고 산업별 진입점을 별도 제공
- 채택할 것: 서비스 분류의 명료함. 단, 효율 규모에는 이중 분류가 과함

### 1-3. 중소기업자금센터 ksbfc.kr (정보 구조형, 효율과 가장 유사한 규모)

메인 페이지 섹션 순서가 그대로 참고할 만함.

1. 최신 정책자금 공고 (게시판 연동, 마감일 표시)
2. 자금 유형 4종을 용도별로 분류 (창업 / 운전 / 시설 / 설립, 각각 사용처 3개씩)
3. 정책자금 스펙 안내 (금리·한도·상환 조건을 수치로)
4. 차별점 3가지 (전문성 / 속도 / 승인률)
5. 컨설팅 프로세스 6단계 (사전진단 → 자금분석 → 서류작성 → 신청 → 결과대응 → 사후관리, 단계마다 세부 3항목)
6. 신뢰와 보장 (선불수수료 없음 명시)
- 독립 메뉴: 성공사례 / FAQ / 자격 진단·금리 계산기(도구)
- 채택할 것: 6단계 프로세스 서술 방식, 용도별 자금 분류, FAQ 독립 배치
- 배제할 것: "85% 승인률, 98% 만족도" 같은 검증 불가 수치 (전략서 원칙과 충돌)

### 1-4. WEDLY (콘텐츠 마케팅형)

1. 히어로: 가치 제안 한 문장 + 무료 상담 CTA + 퀵 액션 3버튼
2. 문제 공감: 대표들의 실제 고민을 인용 부호로 제시 ("무엇부터 해야 할지 막막합니다")
3. 해법 3원칙 (통합 / 전략 / 실행)
4. 서비스 카드 5종: 기능 나열이 아니라 혜택 중심 카피 ("2%대 금리로 현금흐름 확보")
5. 업종별 고민 세그먼트 (제조업 등)
- 채택할 것: 문제 공감 → 해법 구조, 혜택 중심 카피, 서비스 간 교차 연결

## 2. 공통 패턴: 잘 만든 서비스 상세 페이지의 7요소

4개 사이트에서 반복 확인되는 구성임. 현재 효율 사이트의 서비스 페이지는 이 중 1~2번만 있음.

| # | 요소 | 현재 효율 사이트 | 비고 |
|---|---|---|---|
| 1 | 서비스 정의 | 있음 | 기존 홈페이지에서 이관 완료 |
| 2 | 세부 업무 목록 | 있음 | 동일 |
| 3 | 누구를 위한 서비스인가 (대상·상황) | 없음 | WEDLY의 문제 공감 방식 |
| 4 | 진행 프로세스 (단계별) | 없음 | ksbfc의 6단계 방식 |
| 5 | 무엇이 남는가 (산출물·기대효과) | 없음 | 보고서·서류 등 실물 명시 |
| 6 | FAQ | 없음 | 검색 유입 겸용 |
| 7 | 관련 서비스·상담 연결 | CTA만 있음 | 분야 사전 선택 폼으로 강화 |

## 3. 효율경영자문 카테고리별 설계

기존 메뉴 구조 유지. 페이지 내부만 7요소 구조로 확장함.

### 3-1. 경영전략 (service)

| 섹션 | 내용 | 출처 |
|---|---|---|
| 정의 | 기존 문구 유지 | 이관 완료 |
| 이런 상황에 필요합니다 | 정책자금 신청 전 사업계획 정리가 필요한 기업 / 매출 정체로 방향 재정립이 필요한 기업 / 신사업 타당성 검토가 필요한 기업 | 신규 작성 |
| 세부 업무 | 기존 7항목 유지 | 이관 완료 |
| 진행 프로세스 | 현황 진단 → 전략 방향 도출 → 실행계획 수립 → 사업계획서 작성 → 후속 점검 (5단계) | 신규 작성 |
| 산출물 | 경영진단 보고서, 사업계획서, 실행계획서 | 신규 작성 |
| FAQ 3~4건 | 소요 기간, 비용 산정 방식, 정부지원 연계 가능 여부 | 신규 작성 |

### 3-2. 기업인증 (certification)

| 섹션 | 내용 | 출처 |

## 4. 작성 원칙 (전략서 계승)

1. 검증 불가 수치 금지. "85% 승인률" 대신 수행기관 등록 이력과 장관상 등 확인 가능한 사실만 사용
2. 제도 정보(인증 요건·혜택)는 공개된 정부 기준으로 작성하되, 변동 가능성이 있는 수치(금리·한도)는 구체 숫자 대신 "공고 기준" 표기
3. 혜택 중심 카피는 채택하되 과장 배제. "받게 해드립니다"가 아니라 "요건을 진단하고 절차를 대행합니다"
4. FAQ는 실제 상담에서 반복되는 질문 기준. 초안은 작성 후 대표 검수

## 5. 실행 순서 제안

1. 정부지원 컨설팅 (확장 폭 최대, 차별화 직결)
2. 기업인증 (제도 정보 기반이라 즉시 작성 가능)
3. 기업진단 / 경영전략
4. 회사소개 보강, 공지사항 초기 게시물
5. FAQ 전체 검수 (대표)

필요 자료: 등록증 스캔 2종(사업자·중소기업상담회사), FAQ 초안 검수, 전문인력 학력·신규 3인 이력.
