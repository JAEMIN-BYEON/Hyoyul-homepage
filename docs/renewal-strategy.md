# 효율경영자문(주) 홈페이지 재구축 전략

작성일 2026.08.20 / 대상 사이트 https://www.hyoyul.co.kr

---

## 0. 요약

현 사이트는 clickn.co.kr 임대형 빌더로 만들어졌고, 사이트맵에 등록된 15개 페이지 전부가 빌더 템플릿의 예시문구 상태임. 회사 콘텐츠는 관리자 설정에 입력된 기본정보(상호, 대표자, 주소, 연락처) 외에 존재하지 않음. 따라서 이번 작업은 리뉴얼이 아니라 신규 구축으로 규정함.

이전할 콘텐츠가 없다는 점은 제약이 아니라 조건임. 기존 URL 색인 자산이 없으므로 리다이렉트 부담 없이 정보구조를 처음부터 설계할 수 있음.

핵심 결정 네 가지:

1. 포지셔닝은 법무법인·세무법인과 동일한 전문가 조직 구조(자격, 사람, 실적)로 잡음
2. 발주기관명 공개가 가능한 공공기관 수행실적을 사이트의 중심 자산으로 배치함
3. Next.js 기반 자체 구축으로 소스 소유권과 SEO 제어권을 확보함
4. 8주 단위로 진행하되 병목은 개발이 아니라 콘텐츠 작성임을 전제로 일정을 배분함

## 1. 현황 진단

### 1-1. 콘텐츠

15개 페이지 전량이 빌더 데모 문구를 유지하고 있음. 서로 다른 업종 템플릿이 섞여 있어 페이지 간 일관성도 없음.

| 페이지 | 현재 실려 있는 내용 | 원본 템플릿 업종 |
|---|---|---|
| `/` (메인) | "쇼파 컬렉션 / 인테리어 의자 / 1인 가구 · 제품설명이 들어갑니다" | 가구 쇼핑몰 |
| 전 페이지 하단 CTA | "영원히 기억될 최고의 순간을 담아드립니다" | 웨딩 촬영 |
| `/pages/cunsult` | "입주단지 / 분양단지 / 공사단지" | 아파트 분양 |
| `/pages/jaemin`, `/ha`, `/ms`, `/lee` | 윤동주 시 더미텍스트 4개 페이지 동일 | 브랜드 소개 |
| `/pages/service`, `/diagnosis`, `/government`, `/certification` | "트렌디한 디자인 시스템의 UX 통합가이드라인의…" 4개 페이지 동일 | 디자인 에이전시 |
| `/pages/history` | "블록으로 쉽게 꾸미는 빌더" 빌더 자체 홍보 문구 | 빌더 안내 |
| `/pages/gallery` | 더미텍스트 + "MEDIA TECHNOLOGY" | 미디어 |
| `/pages/map` | "서울특별시 한국시외버스터미널에서 00000번 탑승", 전화 "0000-0000" | 기본 양식 |
| `/pages/news` | 등록된 게시글 0건 | 게시판 |

이 밖에 메인 본문에 "테스트" 문자열이 남아 있고, 지도 API 키가 등록되지 않아(`map_api` 전 항목 null) 오시는 길 지도가 표시되지 않음. 관리자 최종 수정일은 2024년 10월 21일임.

문제의 성격은 미완성이 아니라 신뢰 훼손임. 발주기관 담당자나 상담 문의 고객이 검색으로 접근했을 때 웨딩 촬영 문구와 아파트 분양 문구를 보게 되며, 이는 홈페이지가 없는 상태보다 불리하게 작용함.

### 1-2. 검색 노출

| 항목 | 현재 상태 | 결과 |
|---|---|---|
| `<title>` | 15개 페이지 전부 "효율경영자문(주)" 동일 | 페이지 구분 불가, 검색결과 클릭 유인 없음 |
| `meta description` | 15개 페이지 전부 "전문인력 전원 경영지도사" 동일 | 동일 |
| `h1` 태그 | 전 페이지 0개 | 문서 주제 신호 부재 |
| 본문 렌더링 | 자바스크립트 클라이언트 렌더링 | HTML 소스에 본문 텍스트 없음 |

"청주 경영컨설팅", "충북 정책자금" 같은 검색어로 노출될 근거가 페이지에 존재하지 않음. 네이버·구글 사이트 인증 태그는 삽입돼 있으나 색인할 내용이 없어 효과가 없음.

| 항목 | 측정값 |
|---|---|
| CSS 파일 | 39개 |
| JS 파일 | 37개 |

빌더가 모든 기능 모듈을 일괄 로드하는 구조라, 실제 사용하지 않는 쇼핑몰·에디터·업로드 관련 스크립트까지 내려받음.

### 1-4. 플랫폼

clickn.co.kr 임대형 빌더 위에서 운영 중임(세션 쿠키 `hyoyulclickncokr_session`으로 확인). 소스코드 소유권이 없고, 디자인·마크업·SEO 제어 범위가 빌더 허용 범위로 제한됨. 컨설팅 회사에 불필요한 회원가입·로그인·장바구니 메뉴가 노출돼 있음. 슬러그 오타도 남아 있음(`cunsult`).

## 2. 포지셔닝

### 2-1. 전문서비스업의 신뢰 구조

법무법인과 세무법인의 홈페이지는 공통적으로 세 개 축으로 신뢰를 만듦.

| 축 | 법무법인 | 세무법인 | 효율경영자문 적용 |
|---|---|---|---|
| 자격 | 변호사 자격 | 세무사 자격 | 경영지도사 (전문인력 전원 보유) |
| 사람 | 구성원 변호사 프로필 | 구성원 세무사 프로필 | 전문위원 4인 개별 프로필 |
| 실적 | 수임·자문 사례 | 조사 대응·불복 사례 | 공공기관 발주 컨설팅 수행실적 |

기존 슬로건 "전문인력 전원 경영지도사"는 자격 축을 이미 확보한 문장임. 나머지 두 축이 사이트에 전혀 구현돼 있지 않은 것이 현 상태의 본질임.

### 2-2. 차별화 근거

정책자금·사업계획서 시장에는 성공보수 기반 알선형 업체가 다수 존재하며, 이들 사이트는 대체로 "누적 3만 건, 승인율 85%" 형태의 검증 불가능한 집계 수치를 전면에 배치함. 반면 전남신용보증재단, 충남경제진흥원 등 공공기관이 발주한 컨설팅 사업을 수행한 이력은 검증 가능한 제3자 신뢰 자산이며, 알선형 업체가 제시할 수 없는 항목임.

발주기관명 공개가 가능하다는 조건이 확인됐으므로, 이 자산을 사이트 최상위 메뉴로 승격시켜 배치함.

### 2-3. 메시지 위계

메인 페이지 상단부터 순서대로 다음 세 문장이 읽히도록 구성함.

1. 전문인력 전원 경영지도사 (자격)
2. 공공기관이 발주한 컨설팅 사업을 수행하는 자문사 (신뢰)
3. 경영진단, 정책자금, 사업계획서, 기업인증 (서비스)

집계 수치를 쓸 경우 반드시 산출 기준을 병기함. 근거 없는 승인율·만족도 수치는 사용하지 않음.

### 3-2. 신규 정보구조

```
/                        메인
/about                   회사소개
  /about/overview        인사말·회사개요
  /about/history         연혁
  /about/certification   인증·자격·등록증
  /about/location        오시는 길
/practice                전문분야
  /practice/diagnosis        경영진단
  /practice/policy-fund      정책자금·정부지원사업
  /practice/business-plan    사업계획서 수립
  /practice/certification    기업인증 (ISO, 벤처, 이노비즈 등)
  /practice/small-business   소상공인 컨설팅·멘토링
/professionals           전문위원
  /professionals/[slug]  개인 프로필
/track-record            수행실적
  /track-record/[year]   연도별 상세
/insights                인사이트
  /insights/[slug]       공고 요약·칼럼
/contact                 상담 문의
```

메뉴는 6개로 제한함. 법무법인 표준 구조(업무분야 / 구성원 / 소개 / 소식 / 문의)에 수행실적을 추가한 형태임.

### 3-3. 전문분야 페이지 표준 구성

전문분야 하위 5개 페이지는 동일한 골격을 사용함. 이 골격이 검색 유입과 상담 전환을 동시에 담당함.

1. 어떤 기업이 대상인가 (해당 없는 기업이 먼저 걸러지도록)
2. 무엇을 진단하고 무엇을 산출하는가 (산출물 실물 명시)
3. 진행 절차와 소요 기간
4. 실제 수행 사례 (수진업체 익명 처리, 발주기관은 명시)
5. 자주 묻는 질문
6. 상담 문의 (해당 분야 사전 선택 상태)

## 5. 디자인 방향

### 5-1. 기준

법무법인·세무법인 계열의 절제된 기업형 레이아웃을 기준으로 삼음. 정보 밀도는 낮게, 여백은 넓게, 시각적 장식은 최소로 유지함. 디자인이 눈에 띄는 것이 아니라 내용이 정확해 보이는 것이 목표임.

### 5-2. 컬러

| 역할 | 값 | 용도 |
|---|---|---|
| Primary | `#12365E` (딥 네이비) | 헤더, 주요 버튼, 강조 |
| Primary Deep | `#0B2440` | 푸터, 대비 영역 |
| Accent | `#9A6B2F` (브론즈) | 실적 수치, 인증 배지, 밑줄 |
| Ink | `#131A24` | 본문 텍스트 |
| Muted | `#5B6675` | 보조 텍스트, 라벨 |
| Paper | `#F7F8FA` | 배경 |
| Rule | `#DCE1E8` | 구분선, 테두리 |

네이비는 안정성과 권위, 브론즈는 자격·인증의 상징으로 각각 최소량만 사용함. 그라디언트는 사용하지 않음.

### 5-3. 타이포그래피

| 역할 | 서체 | 비고 |
|---|---|---|
| 국문 헤드라인 | Noto Serif KR 600 | 명조체로 권위 표현, 대제목에만 사용 |
| 국문 본문 | Pretendard (또는 Gothic A1) 400/500/700 | 본문 16px, 행간 1.7 |
| 수치·라벨 | IBM Plex Mono 500 | 연도, 건수, 영문 라벨 |

본문 한 줄 길이는 국문 기준 40자 내외로 제한함. 폰트는 필요한 굵기만 서브셋으로 self-host 하여 현재 40여 종을 로드하는 구조를 정리함.

### 5-4. 레이아웃 원칙

- 12컬럼 그리드, 최대 폭 1200px
- 모바일 우선, 분기점 375 / 768 / 1024 / 1440
- 섹션 간 수직 여백 96px 이상 (모바일 64px)
- 카드는 그림자 대신 1px 실선 테두리로 구분
- 모션은 150~300ms 페이드·상승만 사용, `prefers-reduced-motion` 대응

### 5-5. 사용하지 않을 요소

자동 회전 배너, 진입 팝업 레이어, 이모지 아이콘, 보라·분홍 그라디언트, 스톡 인물 사진, 근거 없는 집계 수치, 카운트업 애니메이션.

| 스타일 | Tailwind CSS + CSS 변수 토큰 | 디자인 토큰 일원화 |
| 콘텐츠 | MDX 파일 기반 (초기) | 게시 빈도 월 2~4건 수준이면 CMS 불필요 |
| 배포 | Vercel | 정적 배포, 자동 HTTPS, 프리뷰 환경 |
| 폼 처리 | 서버 액션 + Resend 이메일 발송 | 별도 백엔드 불필요 |
| 이미지 | next/image, WebP·AVIF | 용량 절감 |
| 분석 | GA4 + Google Search Console + 네이버 서치어드바이저 | 유입 경로 측정 |
| 저장소 | GitHub `jaemin-byeon/hyoyul-homepage` | 소스 소유, 변경 이력 관리 |

콘텐츠 등록을 대표가 직접 하되 코드를 다루지 않는 방식이 필요해지면 2단계에서 Sanity 또는 Contentlayer를 추가함. 초기부터 CMS를 붙이면 구축 기간과 유지비만 늘어남.

## 7. 검색 노출 전략

### 7-1. 구조적 조치

- 페이지별 `title`, `description`, OG 태그를 개별 생성함
- 정적 생성으로 HTML 소스에 본문 텍스트를 포함시킴
- `h1` 1개 원칙, `h2`·`h3` 계층 준수
- 구조화 데이터 삽입: Organization, LocalBusiness(청주 소재), Person(전문위원), Article(인사이트)
- `sitemap.xml`, `robots.txt` 자동 생성
- Google Search Console과 네이버 서치어드바이저에 신규 사이트맵 제출

### 7-2. 목표 키워드

| 유형 | 키워드 | 대응 페이지 |
|---|---|---|
| 지역 + 서비스 | 청주 경영컨설팅, 충북 경영지도사, 청주 정책자금 | 메인, 오시는 길 |
| 서비스 | 정책자금 사업계획서 작성, 중소기업 경영진단, 소상공인 컨설팅 | 전문분야 각 페이지 |
| 인증 | 벤처기업 인증 컨설팅, 이노비즈 인증, ISO 인증 컨설팅 | 전문분야 기업인증 |
| 정보 탐색 | 정책자금 신청 절차, 사업계획서 자금집행계획 작성법 | 인사이트 |
| 기관명 | 신용보증재단 컨설팅, 경제진흥원 멘토링 | 수행실적 |

지역 + 서비스 조합은 경쟁 강도가 낮아 초기 유입 확보에 유리함. 정보 탐색 키워드는 인사이트 콘텐츠로 대응하되, 축적에 6개월 이상 소요됨을 전제함.

### 7-3. 네이버 대응

국내 B2B 검색은 네이버 비중이 높음. 서치어드바이저 등록과 별도로, 인사이트 게시글을 네이버 블로그에 요약 게재하고 원문 링크를 거는 방식으로 초기 유입을 보완함.

## 8. 전환 설계

상담 문의까지의 경로를 세 갈래로 만듦.

| 경로 | 접점 | 대상 |
|---|---|---|
| 즉시 | 헤더 고정 전화번호, 모바일 하단 고정 통화 버튼 | 급한 문의 |
| 폼 | 전문분야 페이지 하단 문의 폼 (해당 분야 사전 선택) | 검토 단계 |
| 문서 | 회사소개서 PDF 내려받기 (이메일 입력 후) | 기관·법인 담당자 |

문의 폼 항목은 상호, 담당자명, 연락처, 문의분야, 내용 5개로 제한함. 개인정보 수집·이용 동의 체크박스는 필수이며, 개인정보처리방침 페이지를 별도 게시함.

## 9. 실행 로드맵

| 주차 | 단계 | 산출물 | 담당 |
|---|---|---|---|
| 1주 | 자산 수집 | 수행실적 원장, 전문위원 이력, 인증서 스캔, 사진 촬영 일정 확정 | 효율경영자문 |
| 2주 | 설계 확정 | 최종 IA, 와이어프레임, 디자인 토큰 정의 | 공동 |
| 3주 | 디자인 | 메인·전문분야·전문위원·수행실적 4개 화면 시안 | 개발 |
| 3~6주 | 개발 | Next.js 구축, 전 페이지 구현, 문의 폼 연동 | 개발 |
| 4~6주 | 콘텐츠 작성 | 전문분야 5종 본문, 전문위원 4인 프로필, 인사이트 5건 | 효율경영자문 |
| 7주 | 입력·검수 | 콘텐츠 입력, 크로스브라우저·모바일 검수, 접근성 점검 | 공동 |
| 8주 | 전환 | 도메인 DNS 전환, 색인 요청, GA4·서치콘솔 연동, clickn 해지 | 개발 |

콘텐츠 작성(4~6주)이 전체 일정의 임계 경로임. 개발은 콘텐츠 없이도 병행 가능하나 검수 단계는 콘텐츠가 있어야 시작됨. 4주차까지 전문분야 본문 초안이 나오지 않으면 전체 일정이 그만큼 밀림.

## 10. 준비 자산 체크리스트

착수 전 확보가 필요한 항목임.

- [ ] 연도별 수행실적 원장 (발주기관 / 사업명 / 수행기간 / 역할 / 건수)
- [ ] 전문위원 4인 이력 (성명, 자격, 학력, 경력, 전문분야, 주요 수행실적)
- [ ] 경영지도사 등록증, 사업자등록증, 보유 인증서 스캔본
- [ ] 대표 인사말 초안
- [ ] 인물 사진 촬영 (4인, 동일 배경·조명)
- [ ] 사무실 외경·내부 사진
- [ ] 회사 로고 원본 파일 (AI 또는 SVG)
- [ ] 발주기관명 공개에 관한 계약상 비밀유지 조항 최종 확인
- [ ] clickn 계약 만료일 및 해지 조건 확인
- [ ] hyoyul.co.kr 도메인 등록처 및 관리 계정 확인

로고 원본과 도메인 관리 계정 두 항목은 확인이 늦어지면 착수가 지연되므로 1주차 내 처리가 필요함.

## 11. 리스크

| 리스크 | 영향 | 대응 |
|---|---|---|
| 콘텐츠 작성 지연 | 전체 일정 지연 | 전문분야 5종을 우선순위대로 순차 오픈, 나머지는 준비 중 표기 없이 미노출 |
| 발주기관명 공개 제한 | 핵심 자산 사용 불가 | 계약서 비밀유지 조항 사전 확인. 제한 시 기관 유형(신용보증재단, 경제진흥원)으로 표기 수준 조정 |
| 도메인 전환 시 접속 중단 | 단기 노출 손실 | DNS TTL 사전 단축, 신규 사이트 검수 완료 후 전환, clickn 해지는 전환 확인 후 진행 |
| 기존 URL 색인 손실 | 없음에 가까움 | 현 사이트 색인 자산이 사실상 없으므로 리다이렉트 최소 구성으로 충분 |
| 구축 후 방치 | 6개월 내 현 상태로 회귀 | 인사이트 월 2건 게시를 운영 규칙으로 고정. 게시 부담이 크면 공고 요약 형식으로 대체 |

가장 큰 리스크는 기술이 아니라 운영임. 현 사이트가 2024년 10월 이후 손대지 않은 상태로 방치된 원인을 구조적으로 제거하지 않으면 같은 결과가 반복됨. 인사이트를 부담이 적은 공고 요약 형식으로 설계하는 이유가 여기에 있음.
